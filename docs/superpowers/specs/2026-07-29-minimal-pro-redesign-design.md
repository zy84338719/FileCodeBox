# FileCodeBox 前端极简专业风(Linear/Vercel)全站重设计

- **日期**:2026-07-29
- **范围**:全部页面统一风格(首页 / 登录注册 / 用户区 / 管理后台)
- **方向**:极简专业风(Linear / Vercel),黑白主导 + 冷色强调
- **技术路径**:重写设计 token + 各页 scoped 样式,保持 Vue3 + Element Plus + SCSS 架构

## 背景

当前前端各页面风格割裂、整体观感简陋:

- **首页 home**:紫色全屏渐变 + 浮动光圈 + 毛玻璃导航,是全站最用心的页面,但风格偏"花哨",且与其他页面割裂。
- **登录/注册 Login/Register**:`el-card` 默认样式 + `label-width:80px` 左对齐表单,Element Plus 原始组件裸奔,无设计。
- **用户区 Dashboard 等**:有卡片式设计但偏普通,且**缺少统一应用外壳**(登录后页面直接裸奔)。
- **管理后台**:有深色渐变侧边栏,结构 OK 但与首页风格冲突。
- **隐患**:大量硬编码颜色(`#fff`/`#303133` 等),深色模式存在回归风险。

目标:建立一套贯穿所有页面的设计语言,让全站视觉统一、克制、专业。

## 设计原则

Linear / Vercel 风格的核心特征:

1. **克制**:大面积中性色(白 / 浅灰 / 深灰 / 黑),强调色仅用于关键交互点。
2. **锐利**:细描边(1px border)为主,圆角克制,阴影极轻。
3. **信息密度**:减少无谓留白和装饰,让内容本身成为主角。
4. **去渐变化**:删除全屏渐变背景、浮动光圈、毛玻璃导航。

## 设计 Token(`src/styles/main.scss`)

| Token 类别 | 当前 | 新方案 |
|---|---|---|
| 主色/强调色 | 紫色渐变 `#667eea→#764ba2` | 单色强调 `#5e6ad2`(Linear 紫蓝),仅按钮/链接/激活态 |
| 背景 | 紫色全屏渐变 | `#fafafa`(浅)/ `#0a0a0a`(深),纯净 |
| 表面/卡片 | 白 + 重阴影 | 白(浅)/ `#141414`(深),1px 边框 + 极轻阴影 |
| 边框 | rgba 系半透明 | `#e5e5e5`(浅)/ `#262626`(深),实色 1px |
| 圆角 | 12~24px 混用 | 统一 `--radius: 8px`,大容器 12px,按钮 6px |
| 阴影 | `0 20px 60px` 重阴影 | `0 1px 2px rgba(0,0,0,0.04)` 极轻 |
| 字号 | 不统一 | 系统 `text-xs/sm/base/lg/xl/2xl` |
| 功能性色 | EP 默认 | 微调至更冷调,降饱和 |

**全局 Element Plus 主题覆盖**:通过 EP 的 CSS 变量(`--el-color-primary` 等)把强调色、圆角、边框、阴影统一注入,所有 EP 组件自动跟随。

## 三种布局模式

### 1. 营销布局(首页 / API 文档)
- 顶部 `64px` 固定导航条:纯白/纯黑背景 + 1px 底边框,**毛玻璃删除**。
- 左:Logo(去紫色渐变底,改强调色单色图标 + 黑色文字)。
- 右:语言/主题切换 + 取件码 + 文档 + 登录/头像。
- 主内容区:纯净背景 + 居中容器 `max-width 1100px`。
- **删除**:浮动光圈动画、紫色全屏渐变背景。

### 2. 应用布局(用户区:Dashboard/Shares/History/Notifications)
- 当前缺失——用户登录后页面裸奔。**新增统一应用外壳**。
- 顶部 `56px` 导航条(同营销布局风格)+ 左侧 `220px` 轻量侧边栏(个人中心/分享记录/历史/通知),背景与内容区同色 + 右侧 1px 分隔线。
- 统一的页面标题区。

### 3. 控制台布局(管理后台 admin)
- 保留侧边栏结构,但**深色渐变改为主题同色**(`#fafafa`/`#0a0a0a`),靠 1px 右边框分隔。
- 激活项:强调色文字 + 左侧 2px 强调色竖条(Linear 风激活态),不再用渐变填充。
- 顶栏 `56px`,扁平化。

## 各页面改造细节

### 首页 home(改动最大)
- 删:`.bg-decoration` 浮动光圈、`.home-container` 紫色全屏渐变、`.top-nav` 毛玻璃、`.intro-section h2` 渐变文字。
- 换:纯净背景;Hero 区改为左对齐大标题(黑色)+ 副标题(灰色)+ 主 CTA 按钮(强调色),右侧产品截图/功能卡片。
- 4 步流程图:从彩色卡片改为极简横向时间线(细线 + 圆点 + 数字),删除彩色填充。
- 功能 Tabs(上传/文本/取件):保留,标签扁平化,激活态用强调色下划线。

### 登录/注册 Login/Register(从裸奔到有设计)
- 当前默认 `el-card` + 左对齐表单 → 改为:居中窄卡片(`max-width 400px`)+ 1px 边框 + 极轻阴影 + 顶部 Logo + `label-position:top` + 强调色提交按钮。

### 用户区 Dashboard/Shares/History/Notifications
- 套应用布局外壳(顶部导航 + 左侧菜单)。
- Dashboard 欢迎卡片:去渐变头像底,改纯色;统计数字用大字号 + 灰色标签的 Linear 式数据卡。
- 列表页(Shares/History/Logs):EP 表格统一 1px 边框、删斑马纹、表头加粗 + 浅底。

### 管理后台 8 个页面
- 套控制台布局外壳,侧边栏/顶栏扁平化。
- Dashboard 图表区统一卡片;Config 表单统一;Files/Users 表格同规范。

## 组件与样式规范

- **按钮**:`type="primary"` = 强调色 `#5e6ad2` 实底;default = 白底 1px 边框;圆角 6px;删 hover 上浮动画,改背景微变。
- **卡片**:1px solid border + 极轻阴影 + radius 12px;`shadow="hover"` 改边框加深而非放大。
- **输入框**:EP 默认 + 圆角 6px + focus 态强调色边框。
- **表格**:表头浅底加粗,行高紧凑,1px 分隔线。
- **Tag/状态**:低饱和色 + 浅底深字。
- **头像**:纯色或强调色首字母,删渐变。
- **响应式**:保留 768px 断点,移动端侧边栏收为抽屉。
- **深色模式**:同步覆盖新 token;所有硬编码色改用 token 变量(顺手修复现有隐患)。

## 风险

1. **深色模式回归**:大量写死颜色,改 token 时必须全部替换为变量并测试深色。
2. **Element Plus 内部样式覆盖**:用 `:deep()` 改 EP 组件较脆,EP 升级可能失效,属可接受风险。
3. **工作量**:全站约 18 个文件,改动面大。改完逐页 `npm run dev` 验证视觉 + 深浅色切换。

## 验证方式

每个区域改完启动 dev server(`cd frontend && npm run dev`)实际查看 + 切换明/暗/自动主题确认无回归。
